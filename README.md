# 🍹 Fresh Juice POS System

A lightweight, web-based Point of Sale (POS) application designed to streamline billing, order management, and sales tracking for a fresh juice bar.

## ✨ Features

- **Menu & Category Browsing:** Quick selection of fresh juices, smoothies, and add-ons.
- **Interactive Cart Management:** Add items, adjust quantities, or remove items in real time.
- **Automated Billing:** Instant calculation of subtotals, discounts, and final totals.
- **Order Processing & Receipts:** Clean checkout flow with printable/digital order summaries.
- **Responsive Design:** Smooth layout optimized for desktop and tablet POS screens.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3
- **Logic & State Management:** Vanilla JavaScript (`app.js`)

## 📂 Project Structure

POS-System/
├── assets/         # Images, icons, and stylesheets
├── index.html      # Main application entry point and POS interface
├── app.js          # Core POS logic, cart calculations, and DOM manipulation
└── README.md       # Project documentation

## 🚀 Getting Started

1. **Clone the repository:**
   git clone https://github.com/Prasanna-Perera/POS-System.git

2. **Navigate to the project directory:**
   cd POS-System

3. **Run the application:**
   - Open `index.html` directly in your web browser, **or**
   - Use a local development server (such as the **Live Server** extension in VS Code) for the best experience.
